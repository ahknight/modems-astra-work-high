# Development journal

Started from the empty public repository. Adopted a build-free, local-first publication for GitHub Pages. Eight listening chapters share one transport. Collected museum records, a contemporary BYTE notice, participant oral histories, standards edition records and signaling clauses. Kept the original and revised V.34 editions separate. The narrative and references should survive disabled JavaScript. Keep the sender tracks separate so that the oscilloscope and spectrum can inspect the same samples the visitor hears.

## 2026-11-20 · Listening instruments

Implemented eight deterministic transmitter examples with independent caller and answer PCM. The Bell 103A2, V.22 and V.22bis examples reach asynchronous 8N1 payload. A clean-line independent receiver recovered the greeting and reply from all six stems using known clocks. This verifies the encoded bits under those assumptions. No modem hardware has been connected.

V.32 and V.32bis cover ranging, specified training sequences and rate words. Original and revised V.34 include V.8 menus and checked INFO/MP words, probe tones with the specified phase signs, and receiver training. Verified published scrambler prefixes, all 21 probe components and four vacant frequencies, the 6 dB L1/L2 step, and control CRC checks. The two editions use different guard levels. The V.34 samples end at E, before B1 and user payload. V.90 joins documented fragments at native speed and reaches actual downstream text. An inverse mapper and descrambler recovered its B1 ones and text. The signal methods document timing choices, channel assumptions and omitted exchanges.

The waveform, short-time spectrum, full-call map, playhead and sound share the sample arrays. AudioContext time drives playback position; persistent stage descriptions can be selected for inspection. The map uses a Hann-windowed spectrum, with caller and answer drawn separately. Reduced motion freezes the detail plot at each stage. No external player, library or media host is required.
